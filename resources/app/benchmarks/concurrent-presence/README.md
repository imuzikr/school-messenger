# 70명 동시 접속 검증

2026-11-06, Windows 개발 PC에서 측정했습니다. 기준 서버·화면 갱신 코드는 `c6396c0b1acf82533613a26db5f3c954d3a0885d`(0.2.135)이며, 같은 합성 데이터와 시험 코드로 수정 전후를 비교했습니다. 기존 7번 첨부 대기열 수정은 유지했습니다.

## 시험 조건

- 별도 Node 프로세스의 실제 HTTPS/SQLite 서버, 계정 70개, 공유 일정 700개와 업무 배정 140개.
- 각 계정에 실제 `PrivateClient`, 독립 PC SQLite 저장소, 실제 `DingdongBackend`, SSE 연결을 하나씩 사용합니다.
- 70개 인증된 세션의 동시 접속, 10개 연결 종료·재접속, 69명 대상 암호화 단체 메시지, 전원/두 명 대상 일정 변경, 서버 설정 백업을 순서대로 실행합니다.
- 계정·세션은 합성 데이터로 준비합니다. 70명 신규 비밀번호 로그인 시험은 아닙니다. 한 PC의 동일 IP에서 비밀번호 검사 제한을 우회하지 않습니다.
- 이 부하 시험은 화면 렌더링·DPAPI·학교 네트워크를 포함하지 않습니다. 모든 가상 클라이언트가 같은 프로세스에서 실행되므로 메시지 수신 시간은 실제 학교 PC 70대의 예상 속도가 아닙니다.
- 서버 CPU, 이벤트 루프 지연, SQL 실행 수, 실제 HTTP 응답 수·크기·시간을 측정합니다. SQL 계측은 준비문의 `all/get/run` 실행 수이며 `exec`와 VACUUM 등은 제외합니다. 단계별 안정화 확인 대기 시간은 단계 총시간에 포함됩니다.

## 반영한 변경

- 접속 상태를 별도 SSE 데이터로 전송하고 100 ms 동안 몰린 접속 변경을 묶습니다. 같은 사용자의 마지막 연결이 끊길 때만 미접속으로 바뀝니다.
- 서버 실행 식별자와 상태 순번으로 오래된 전체 조회 응답이 최신 접속 표시를 되돌리지 않도록 합니다. 이전 서버의 단순 알림은 기존 전체 조회로 처리합니다.
- 클라이언트 전체 조회는 한 번에 하나만 실행합니다. 진행 중 도착한 변경은 후속 조회 한 번으로 합치며, 캐시로 대체한 연결 실패는 3초 뒤 재시도합니다.
- 접속 표시만 바뀔 때 조직도 표시와 접속 인원을 직접 갱신하여 입력·검색·포커스를 유지합니다.
- 전체 조회 한 번 안에서 일정 파싱, 업무 설정, 오늘 날짜, 업무 교환 문맥을 재사용합니다.
- 일반 공유 일정 변경은 등록자와 변경 전후 참여자에게 알립니다. 전체 업무 배정·학교 설정 등은 전체 알림을 유지합니다.
- 설정 백업은 메시지에 연결된 일정 ID를 한 번 모아 조회합니다. 개인 메시지·첨부 등을 백업에서 제외하는 규칙은 유지합니다.

## 다시 실행

`resources/app`에서 `npm run test:load`를 실행합니다. 결과는 저장소 루트 `.artifacts/concurrent-presence/current.json`에 저장됩니다. 테스트용 데이터 폴더와 서버는 종료 시 정리됩니다.

기준 코드와 비교하려면 별도 폴더에 해당 커밋의 `server/index.cjs`를 `index.cjs`, `js/backend.js`를 `backend.js`로 저장한 뒤 `node tests/concurrent-presence.cjs before <기준 코드 폴더>`를 실행합니다. 시험용 로더는 다른 의존성과 클라이언트를 유지하면서 이 두 파일만 기준 버전으로 실행합니다. 현재 소스는 변경하지 않습니다.

회귀 검증은 `npm test`, 실제 Windows 화면 검증은 `node tests/privacy-native.cjs`로 실행합니다. 화면 검증에는 접속 상태 변경 중 검색 입력의 DOM 노드·값·포커스 보존이 포함됩니다. 학교 실기기 사이의 방화벽·LAN 지연·재부팅 검증은 별도로 필요합니다.

최종 코드에서 `npm test` **129/129 통과**(약 38.9초). Windows Electron 44.7.0 화면 시험도 통과했습니다. 접속·미접속 전환 중 검색 입력과 포커스 보존, 송수신 상태, 수신 오류 복구, 예약 발송, 첨부 제한, 서버 원문 삭제와 오프라인 읽음 확인을 확인했습니다. 실제 500 MiB 첨부 화면 전송은 이번 실행에서 선택하지 않았습니다.
