# 회신·제출 현황과 통합 검색 · 0.2.118

## 회신·제출 현황

- 메시지함 → 새 메시지 쓰기 → **회신·제출 완료 요청**을 선택합니다. 제출/회신 종류와 선택 사항인 마감일을 정할 수 있습니다.
- 받는 사람만 완료 요청 대상이 됩니다. 참조 수신자와 발신자 본인은 제외합니다.
- 수신자는 메시지의 **제출/회신 완료 알리기**에서 완료와 메모를 기록하고, 필요하면 미완료로 변경할 수 있습니다. 자료 자체는 기존 답장/첨부 기능으로 보냅니다.
- 보낸 메시지함에서 발송 대기, 상대 PC 저장 완료 인원, 읽음 인원을 확인합니다. 회신·제출을 요청했으면 업무 완료 인원도 함께 표시합니다. 메시지 본문의 **수신자별 현황**에서 PC 저장, 읽음, 회신 또는 제출을 각각 확인할 수 있습니다. 요청 목록에서 바로 응답해도 원문을 열 때까지 읽음 알림은 발생하지 않습니다. 개인 캘린더의 완료 체크에는 영향을 주지 않습니다.
- 전체 현황의 요청 목록은 마감일 내림차순으로 표시합니다. 같은 마감일은 최근 발송순이며, 마감일이 없는 요청은 아래에 모읍니다. 보낸 요청과 받은 요청에 동일하게 적용합니다.
- 미완료자를 선택하면 재안내 초안이 열립니다. 보내기 전 수신자와 내용을 검토할 수 있습니다. 원 요청의 현황을 유지하며 재안내에서 일정/마감을 중복 생성하지 않습니다. 실제 서버는 발송 시점에 완료 여부를 다시 확인하고 이미 완료한 사람은 제외합니다.
- 예약 대기와 회수된 수신자는 현황 집계에서 제외합니다. 서버는 인증된 대상자 본인의 응답만 허용하고, 개별 메모는 발신자와 응답자에게만 반환합니다.
- 데모 현황판 하단 **체험 요청 추가**로 보낸 요청/받은 요청 예시를 추가할 수 있습니다. **수신자 체험**은 데모에만 표시됩니다. 실제 발송이나 계정 변경은 없습니다.

## 통합 검색

- 본창 왼쪽 **통합검색**, 작업 창 위쪽 **통합 검색**, 또는 Ctrl+K로 엽니다.
- 메시지 제목/본문, 대화 내용, 일정/마감의 제목·내용·장소, 첨부파일 **이름**을 검색합니다. 파일 내부의 문서는 검색하지 않습니다.
- 유형, 발신자/등록자, 시작일/종료일을 조합할 수 있습니다. 메시지/첨부/대화는 발송일, 일정은 일정 날짜를 사용합니다.
- 결과는 날짜 내림차순으로 50개씩 표시합니다. 결과를 선택하면 해당 원문이나 일정 상세로 이동합니다. 첨부파일 결과는 원 메시지를 엽니다.
- 휴지통 메시지는 제외합니다. 실제 서버에서는 본인의 메시지, 참여 중인 대화방, 열람 가능한 일정만 검색합니다. 최근 500개 밖의 오래된 대화도 검색합니다.

## 실행과 검증

이 폴더는 Electron 배포본의 소스입니다. 데스크톱 앱은 트레이 메뉴의 **띵동 종료**로 완전히 종료한 뒤 다시 실행해야 새 작업 창과 서버 요청 경로를 적용합니다. 실제 학교 서버에서 사용하려면 서버와 클라이언트를 함께 업데이트해야 합니다.

개발 검증: `npm install` 후 `npm test`. 임시 데이터 폴더와 로컬 HTTPS 서버를 사용하며 실제 교내 서버에 접속하지 않습니다.
