# 띵동 · 0.2.124

화면, 알림, 문서, JavaScript 공개 이름, IPC 이름, 실행 옵션, 아이콘 파일명과 패키지 이름은 띵동 / Dingdong으로 변경했습니다. 실행 파일은 `Dingdong.exe`, 새 개인 보관 파일의 확장자는 `.dingdong`입니다.

기존 기록을 보존하기 위한 호환 정보는 유지합니다.

- 기존 `IeumClient`, `IeumServer`, `IeumDemo` 폴더가 있으면 계속 사용합니다. 새 PC는 `DingdongClient`, `DingdongServer`, `DingdongDemo`를 사용합니다.
- 기존 서버의 `ieum.sqlite`가 있으면 그대로 열고, 새 서버는 `dingdong.sqlite`를 만듭니다. 인증서와 계정도 유지합니다.
- 브라우저의 이전 저장 키를 새 키로 한 번 복사합니다. 새 키에 이미 값이 있으면 덮어쓰지 않고, 원본은 복구용으로 남깁니다.
- 설치형 화면의 내부 URL 출처, 암호문 형식 식별자, 본문 이미지 참조는 과거 기록과 통신 호환을 위해 유지합니다. 제품 화면에 표시하는 이름은 아닙니다.
- 이전 `.ieum` 보관 파일과 기존 실행 옵션도 읽을 수 있습니다.

`.backups`와 `.artifacts`의 과거 백업·화면·시험 기록은 당시 결과를 보존하므로 소급 변경하지 않습니다. 외부에 이미 만든 바로가기나 배포본도 자동으로 바꾸지 않습니다.

후속 보완: 여러 창에서 로그인·보안 조회를 동시에 해도 키를 한 번만 생성합니다. 첨부는 본문 이미지 포함 최대 20개, 개별 2 MB, 합계 3 MB로 작성 화면부터 확인합니다. 자동 실행 설정에는 클라이언트/서버 모드를 명시합니다.
